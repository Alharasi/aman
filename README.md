# PMO.guide

صفحة عربية خفيفة لأداة PMO Portfolio Toolkit.

## ما تقوم به الصفحة

- تحميل النسخة المعتمدة من ملف Excel.
- فتح ملف PMO Portfolio Toolkit من جهاز المستخدم وعرض المشاريع مباشرة داخل المتصفح.
- لا يتم إرسال محتوى ملف Excel إلى خادم الموقع.
- الحقول الاختيارية الفارغة لا تمنع العرض.

## النشر على GitHub Pages

1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. من Settings > Pages اختر Deploy from a branch.
3. اختر الفرع main والمجلد /(root).
4. عند تجهيز الدومين المخصص، أضفه من Settings > Pages > Custom domain.

ملاحظة: قارئ Excel يتم تحميله من jsDelivr عند فتح الصفحة، لذلك يلزم اتصال إنترنت عند استخدام زر عرض الملف.
