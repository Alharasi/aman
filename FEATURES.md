# about.cv Template Features

A lightweight professional personal-profile template designed to present identity, expertise, biography, and contact information in a fast, polished experience across devices.

- Arabic-only, English-only, or bilingual mode.
- Configurable default language in bilingual mode.
- Full RTL and LTR support.
- Responsive mobile and desktop layout.
- Profile image customization by simply replacing the image file.
- Centralized content configuration for fast and reliable updates.
- Built-in SEO with canonical URL, robots, sitemap, Open Graph, Twitter Cards, and Schema.org Person structured data.
- Social-sharing metadata for messaging apps and social networks.
- Default GitHub, LinkedIn, Instagram, and Website demo links make the icon system visible out of the box; empty links remain hidden.
- Smooth touch, mouse-wheel, keyboard, and button navigation.
- Built with Astro and exported as fast, indexable static HTML.
- No database or backend server required.
- Suitable for GitHub Pages and other static hosting platforms.
